# 绘制配方 Drawing Recipes

读完 `styles.md` 选定布局、读完 `visual_primitives.md` 选好图种语汇后再读本文。
这里给的是**推荐数值**和**底线规则**——推荐值可以微调，底线规则不要破。

---

## 画布尺寸（推荐）

| 布局类型             | viewBox            | 说明                               |
| -------------------- | ------------------ | ---------------------------------- |
| 水平流程 / 双轨      | `1600 × 600~800` | 宽 > 高，留出箭头与标签空间        |
| 分层网络 / 树 / 泳道 | `1600 × 900`     | 接近 16:9，适配 PPTX 幻灯片        |
| 模块系统 / 循环      | `1400 × 1000`    | 偏方形，容纳上下分层或环形布局     |
| 放射状               | `1200 × 1100`    | 接近正方形，卫星节点四面展开       |
| 网格矩阵             | `1500 × 900`     | 视行列数微调：每多一列宽 +220      |
| 时间轴               | `1600 × 750`     | 扁宽，主轴横贯，上下各留卡片空间   |

- viewBox 一旦定下，**所有元素必须在内部**（验证器会查越界）。
- 内容四周留至少 40px 边距；标题区通常占顶部 90~110px。
- 如果用户的内容很多/很少，**画布可以放大或缩小**，不必死守上面这些数。判断标准：渲染出来不要太空，也不要太挤。

## 圆角与尺寸（建议值，但要内部一致）

底线：**同一张图内，圆角/边框/字号必须风格统一**。一张图里别同时出现 rx=4 和 rx=14。

| 元素 | 建议 rx | 说明 |
| ---- | ------- | ---- |
| 容器（大背景框） | 10~16 | 工程风可选 0~4，柔和风可选 16~20 |
| 普通模块 | 4~8 | |
| 圆形/胶囊节点 | 直接用 circle 或 rx=高度/2 | |

间距底线：
- **容器与容器**之间至少留 50px（不然连线挤）。
- **模块与模块**（同容器内）至少留 8px。
- **文字与边框**之间至少留 12px。

字号梯度（推荐）：
- 主标题 24~28pt 粗体
- 容器标题 18~22pt 粗体
- 模块主标签 14~16pt
- 模块副标签 / 注释 11~13pt
- 数学公式可放大到 16~18pt

## 文字排版（这一节是底线，不是建议）

1. **预估宽度** ≈ 字符数 × 字号 × 0.6（中文按 1.0，英文按 0.55）。
   预估宽度 > 容器宽 − 24 → 必须换行或缩字号。
2. **换行**：SVG 不自动换行。用多个 `<text>` 或 `<tspan dy="字号×1.4">`。
3. **垂直堆叠**：容器内首行 y = 容器顶 + 32，之后每行 +20~24，底部注释 y = 容器底 − 14。
4. **居中**：`text-anchor="middle"`，x = 容器中心。左对齐标题 x = 容器左 + 20。
5. **绝不允许**文字跨越形状边界、压住另一段文字。画完按上面的宽度公式过一遍。

## 连接线与箭头

- `<defs>` 里必须先定义 `marker`，实线箭头主色，虚线箭头浅一档。
- `marker-end` 引用的 id 必须存在，否则验证器报错。
- 连接线起点/终点**贴在容器边缘**，不要从容器中心发出（会被容器盖住）。
- 正交连接（树、泳道、分层）走水平+垂直直角段，不画斜线。
- 曲线连接（反馈、放射）用二次贝塞尔 `Q`，弧度平缓。
- 同类连接线**样式必须一致**：实线 = 主数据流，虚线 = 跳跃/反馈/共享，粗线（3px+）+ accent 色 = 关键回路。

## 各布局的专属坐标提示

**01 分层网络**：容器横向排开，容器内模块按行码放；阶段间用粗一点的连接线（2.5px）；残差用虚线 path 绕过主路径。
**如果是 CNN 论文** → 容器内的模块不要全画矩形，至少 1-2 个换成"透视特征图"片段（见 visual_primitives.md），否则一眼看出是 AI 生成的占位图。

**02 水平流程**：每个模块 200~220 宽、150~160 高，模块间隔 60~70。
步骤序号用左上角 circle + 数字徽章。
**如果是数据 pipeline** → 步骤之间的箭头上方应该有一个小缩略图占位（48×48 圆角小框），代表"这一步处理完的数据样例"。

**03 模块系统**：按"层带"组织（UI/核心/存储），每带一个浅色长条容器。跨层箭头**最好标注 protocol/data type**（REST、gRPC、tensor 等），否则就是一堆灰箭头。

**04 层级树**：深度决定颜色（根=lavender，中层=blue，叶=mint）。父底中点向下引线，到一条水平母线，再分别下引到各子节点顶部。全程正交。

**05 循环**：节点放东南西北，中心 hub 圆；闭环用 4 段 Q 曲线顺时针相连。
**关键**：闭环箭头要比普通箭头**粗一档（3px）+ 用 accent 色**，否则"循环"这个核心信息就被埋没了。要留一个"退出条件"出口避免悬空。

**06 双轨**：上下两条轨，**必须用两个明显不同色系**（不是同色调的深浅，而是真的两个家族色，比如蓝家族 vs 橙家族）。两轨模块 x 坐标尽量对齐才能横向对比。交叉连接用虚线。

**07 网格矩阵**：行标签列固定宽（~240），数据列等宽（~215）；表头行 ~70 高，数据行 ~92 高。
**关键**：必须有一行（通常是"Ours"）用 accent 色描边或填色高亮，并把该行的最佳数字**加粗**——否则矩阵就只是个普通表格，没有论文图的"主张"。

**08 放射状**：hub 居中，卫星沿半径 R 的圆周等角分布（N 个则每 360/N 度一个）；先画连接线再画节点（节点压住线头）；卫星卡片尺寸**全部一致**。
**关键**：中心 hub 要用 accent 色，比卫星明显大一圈（1.3~1.5 倍直径），否则没有"中心感"。

**09 泳道**：左侧角色 gutter 固定宽（~170），泳道等高；步骤块垂直居中于所在泳道；跨泳道换手用正交连接；顶部可加阶段标尺。

**10 时间轴**：一条主轴横贯；里程碑节点等间距；卡片**上下交错**（奇数在上、偶数在下）避免重叠；节点用实心圆+白描边。
**关键**：重大里程碑用 accent 色 + 比普通节点大一圈，否则时间轴上所有事件视觉权重一样，看不出重点。

## 配色

- 默认从 `palettes.md` 选**一个**调色板，全图用它 + 共享 neutrals。
- 容器用 `fill`（浅色），模块用 `solid`（饱和色），边框用 `solid` 或其 80% 不透明度。
- 饱和块上文字用白色；浅块上文字用 `#1F2937`。
- **允许的例外**（见 palettes.md）：
  - **重点高亮**：用 accent 色突出 1 个模块/行/列。
  - **双轨对比**：双轨图允许两个调色板各占一半，两轨色系明显不同。
  - **数据流彩虹**：每个数据流用一个色，前提是色不超过 5 种且来自同一调色板。
- 其他情况下混用调色板会让图变花，不要做。

## 失衡感的来源（最常见的丑图原因）

按出现频率排序，画完按这个清单排查：

1. **同层级容器高度不一**：把所有同层级容器对齐到同一高度。
2. **某个模块文字超长导致只有它特别宽**：缩字号或换行，让模块等宽。
3. **箭头线粗细不一**：所有同类箭头用同一 stroke-width。
4. **饱和色和浅色比例失调**：饱和模块密集挤在一处，其他地方全是空白。摊开来。
5. **legend 块比主图还显眼**：legend 缩小到角落，用浅色边框、不要饱和填色。

## 最终自检

- [ ] 所有元素在 viewBox 内，无越界。
- [ ] 没有任何文字重叠、跨界、压线。
- [ ] 所有箭头都有可见箭头头，方向正确；虚线与实线视觉可区分。
- [ ] 含中文时 `font-family` 是 CJK 优先，无豆腐框。
- [ ] 单一调色板（或合规的例外），同层级尺寸均衡，无局部过大。
- [ ] 没有悬空分支：每条路径都终止或汇合。
- [ ] **图种"皮肤"到位**：CNN 图有特征图、对比图有 accent 高亮、循环图有粗回环、双轨图有双色系。
- [ ] `python render_helpers.py validate` 跑一遍，0 problem。
