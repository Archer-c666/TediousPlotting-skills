## 什么情况下使用本 skill

仅当以下三条**全部**成立时触发：

1. 用户想要的是**交互式可视化**（悬停、点击、下钻、刷选），而非静态图表
2. 数据形态匹配本 skill 覆盖的 11 种模板类型之一（层级、流向、网络、矩阵、多维、地理、周期、二维交叉、时序事件）
3. 交付物是**独立可运行的 HTML 文件**

**不适用：** 一般的月销售条形图、简单折线趋势图、单一散点图——这些应该走通用 D3 路线，不需要本 skill 的重型模板。

**判断速查：**

| 用户问什么                                    | 适用？ |
| --------------------------------------------- | ------ |
| "做一张可以点击下钻的层级图"                  | ✅     |
| "我想看资金从哪儿流到哪儿，要能 hover 看明细" | ✅     |
| "比较5家公司在6个维度上的画像"                | ✅     |
| "给我画个柱状图"                              | ❌     |
| "做一份静态信息图打印出来"                    | ❌     |

## 工作流

```
1.探数据形态 如果用户已经清楚说出图类型 → 直接进入第 2 步。 如果用户只描述了数据和需求 → 你必须先问清楚：
- 数据是层级的（树状）、网络的（图状）、流向的（多阶段）、还是表格的（多列属性）？
- 主要分析任务是什么？比较占比？发现聚类？追溯路径？看时间分布？
- 数据规模？（叶节点数、节点数、记录数、维度数）

2.学习references/selection-guide.md它列出了每种习语的适用条件、强项、弱项、扩展上限。先把它读完再做推荐

3.推荐1-2个候选并说明理由
不要静默挑一个直接开做 给用户两个有理有据的候选：
> 根据你的描述，建议：
> 首选：旭日图——你的数据是 3 层树，用户既想看占比又想下钻，这正是旭日图最擅长的角度编码 + 径向下钻。
> 备选：矩形树图——如果你更关心"哪些叶节点最大"而非层级本身，矩形树图的面积编码会更精确。
> 你倾向哪个？
让用户最终拍板，但你已经把功课做完了。

4.读取学习并填充模板
确定图类型后，按顺序读取：
assets/<图类型>/template.html      ← 要填的 HTML 主体
assets/<图类型>/notes.md           ← 占位符清单、定制提示、已知限制
assets/<图类型>/sample-data.json   ← 仅在用户未提供数据时用作回退示例
references/design-system.md       ← 配色 / 字体 / 布局 / 动效规范

5.完成自检项并输出
```

## 模板填充规则

把 `template.html` 里每一个 `{{占位符}}` 替换成实际内容。

### 所有图共享的通用占位符

| 占位符             | 填什么                            | 示例                                             |
| ------------------ | --------------------------------- | ------------------------------------------------ |
| `{{TITLE}}`      | 浏览器标签页标题                  | `全球碳排放结构 2023`                          |
| `{{EYEBROW}}`    | 顶部小标签，等宽大写              | `可视化习语 · TREEMAP · 气候数据`            |
| `{{H1_LEFT}}`    | 主标题左段                        | `全球碳排放的`                                 |
| `{{H1_EM}}`      | 主标题中段（斜体高亮）            | `结构性失衡`                                   |
| `{{H1_RIGHT}}`   | 主标题右段（可空，可含 `<br>`） | `——按区域、行业、源头拆解。`                 |
| `{{LEDE}}`       | 1-2 句引导文，结尾给交互提示      | `点击任意区块下钻到细分行业。悬停看具体数值。` |
| `{{META_TITLE}}` | 右上角主标题                      | `Climate Atlas 2025`                           |
| `{{META_SUB}}`   | 右上角副标题                      | `Earth Systems`                                |
| `{{META_DATA}}`  | 数据来源标注                      | `IEA / 2023`                                   |
| `{{UNIT}}`       | 单位短串                          | `GT CO₂` 或 `users` 或 `$M`               |
| `{{DATA}}`       | 数据字面量（结构按图而定）        | 见各 notes.md                                    |
| `{{COLORS}}`     | 分类色映射对象                    | `{ "Asia": "#e36a4a", "Europe": "#7fb8a4" }`   |

### 每张图特有的占位符

详见对应 `assets/<图类型>/notes.md`。

## 自检清单

输出前请逐条对照：

### 数据与内容

- [ ] 用户给的真实数据**原样使用**——不要伪造、不要"四舍五入"
- [ ] 用户没给数据时，用对应图的 `sample-data.json` 并**主动告知用户**这是示例
- [ ] 数据规模在该图的扩展上限内（见 selection-guide.md），否则向用户提示风险或建议预聚合
- [ ] 标题、副标题、引导文与数据主题对齐——别留着模板的"climate"字样去画游戏数据

### 视觉规范

- [ ] 字体只用 Fraunces + Inter Tight + JetBrains Mono 三件套
- [ ] 默认深色主题 + 琥珀色强调（`--accent: #f0c674`），除非用户明确改色
- [ ] 分类色板是 design-system.md 里定义的 7 种色相之一（不要随手编色）
- [ ] 所有数值用等宽字体或 `tabular-nums`
- [ ] 强调色仅用于：焦点元素、悬停态、激活选区、主操作——不要撒得到处都是

### 交互完备性

- [ ] 悬停 → 高亮目标 + 其他元素变暗到 22% 透明度
- [ ] 有 tooltip 跟随光标（偏移 +18,+18），含名称 + 路径 + 1-3 项数值
- [ ] 右侧详情面板会联动更新
- [ ] 入场有错峰动画（`delay: i * 12ms`）
- [ ] 所有过渡 ≤ 900ms，没有阻塞首次交互的长动画

### 无障碍

- [ ] 灰度模式下分类色仍可区分
- [ ] 颜色不单独承载语义（搭配位置/标签/形状）
- [ ] 正文对比度 ≥ 4.5:1
- [ ] 没有红绿单独表义

### 代码可运行性

- [ ] 把所有 `{{占位符}}` 都替换完了——`grep "{{" output.html` 应为空
- [ ] D3 CDN 链接保留（`https://d3js.org/d3.v7.min.js` 及附加包）
- [ ] 数据字面量是合法的 JS 对象（注意尾逗号、引号）
- [ ] 直接 `open output.html` 能在现代浏览器跑起来

## 定制对照表

用户提常见调整需求时按这张表对应：

| 用户需求                | 怎么做                                                              |
| ----------------------- | ------------------------------------------------------------------- |
| 改强调色                | 覆盖 `--accent` CSS 变量；同步改 tooltip 色带                     |
| 整体换主题色            | 替换 `categoricalPalette` 数组（见 design-system.md）             |
| 改浅色主题              | 把 `--bg-0/1/2` 改成浅色 + 把 `--ink/ink-dim` 反色，并测对比度  |
| 隐藏 tooltip            | 删 `.tip` 节点 + 移除 `showTip` 调用                            |
| 隐藏详情面板            | 把 `.stage` 改成单列 + 删 `.panel-detail`                       |
| 数据条目超上限          | 建议换图，或预聚合小类目为"其他"                                    |
| 想要打印 / 嵌入静态报告 | 本 skill 不适合；建议生成 SVG 静态图                                |
| 想要键盘导航            | 给主要 mark 加 `tabindex="0"` + `focus` 样式 + 监听 `keydown` |
