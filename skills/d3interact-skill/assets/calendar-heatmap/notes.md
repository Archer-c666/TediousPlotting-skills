# Calendar Heatmap 日历热力图 — 使用说明

## 何时使用
每天（或每个时段）一个数值，跨越数周/数月/数年。最适合发现周期规律（周末效应、季节性、节假日异常）和长趋势中的离群点。

典型场景：GitHub 贡献图、网站访问量、销售日历、健康数据（步数/睡眠）、API 调用日志。

## 必填占位符

通用部分（同 SKILL.md 总占位符表）：
`TITLE / EYEBROW / H1_LEFT / H1_EM / H1_RIGHT / LEDE / META_TITLE / META_SUB / META_DATA / UNIT / DATA`

本图特有：

| 占位符 | 填什么 | 示例 |
|--------|--------|------|
| `{{ROOT_NAME}}` | 详情面板默认状态的名字（通常是数据集名） | `2024 contributions` |
| `{{UNIT_LOW}}` | 颜色刻度左端标签（低值） | `low` 或 `0` |
| `{{UNIT_HIGH}}` | 颜色刻度右端标签（高值） | `high` 或 `peak` |
| `{{ACCENT_COLOR}}` | 主梯度终点色（十六进制） | `#f0c674` (琥珀) 或 `#7fb8a4` (鼠尾草绿) |

## 数据结构

数组，每条 `{ date: ISO 日期字符串, value: 数值 }`。日期可以有缺口——缺失的日期会渲染为灰色"无数据"格子。

```javascript
[
  { "date": "2024-01-01", "value": 23 },
  { "date": "2024-01-02", "value": 18 },
  { "date": "2024-01-04", "value": 0 },     // 0 也算"无活动"
  { "date": "2024-01-05", "value": 41 }
]
```

跨年数据会自动按年分组——工具栏的年份按钮可以切换。

## 交互

| 操作 | 结果 |
|------|------|
| 悬停日格 | tooltip 显示日期 + 数值 + 星期；其他格变暗；详情面板更新 |
| 点击日格 | 锁定选中（焦点环），可用于截图标注 |
| 点击 ◀ / ▶ | 切年（仅当有多年数据时启用） |
| ← / → 键 | 同上 |
| Tab + Enter | 键盘导航日格 |

附加视图：右下两个小图分别是**周分布**（周一-周日平均值）和**月分布**（每月总和），与主图共享同一年数据，自动联动更新。

## 颜色刻度

5 档明度递增，从 18% 透明到完全不透明。数值通过 `d3.scaleQuantize` 分桶——这意味着颜色辨别约 5 级（人眼对连续梯度精确读数能力的上限）。如需精确数值，看 tooltip。

零值与缺失值都用 `--cell-empty` 灰色（避免假阴性歧义）。

## 定制需求

| 用户需求 | 怎么做 |
|---------|--------|
| 改主梯度色（如绿色仿 GitHub） | 把 `{{ACCENT_COLOR}}` 改成 `#7fb8a4`（鼠尾草）或 `#6a9bd1`（钢蓝） |
| 周从周日开始 | 把 `dayOfWeek` 改为 `d => d.getDay()`，调整 `WEEKDAY_LABELS` 顺序 |
| 显示小时级（24h × 7day） | 把 cell 网格改成 24 列 × 7 行；按小时 rollup |
| 隐藏年份切换 | 删除 `.toolbar` 节点 + `renderCalendar` 里相关 `#currentYear/prevYear/nextYear` 引用 |
| 隐藏底部周/月分布 | 删除 `.secondary` 节点 + `renderWeekdayChart` `renderMonthChart` 调用 |
| 改色刻度档数 | 修改 `colorScale.range([...])` 的数组长度（建议 3-7 档） |
| 用发散色（如 ±0 中心） | 替换 `colorScale` 为 `d3.scaleDiverging(d3.interpolateRdBu).domain([min, 0, max])` |
| 周末高亮 | 已默认：周分布图中周六/周日用 `--accent-2` 赤陶色 |

## 限制

- 单年数据超过 366 天会出现重叠（不应该出现）；多年数据靠工具栏切换
- 一行 7 个工作日是硬约束，不能改成 5 工作日制（会破坏对齐）
- 颜色梯度无法精确读数 → 必须保留 tooltip
- 移动端 < 680px 时单元格变小，触摸命中精度下降；可考虑只显示当月视图

## 已知陷阱

- **时区**：`new Date("2024-01-01")` 在 UTC-8 时区会解析成 2023-12-31。如果你看到日期偏移一天，把日期字符串改成 `"2024-01-01T12:00:00"` 中午锚定避开夏令时跳变。
- **缺失日期 vs 0 值**：本模板把两者都渲染为灰色。如果你需要区分（"无数据" vs "明确为 0"），在 `colorFor` 里区分 `undefined` 和 `0`。
